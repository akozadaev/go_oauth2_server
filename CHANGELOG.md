# История изменений

## v1.2.0 - 2026-11-09

### Возможности

- Добавлены роли пользователей и claim `roles` в JWT, миграция хранения ролей.
- Расширена OpenAPI-документация endpoint-ов и моделей регистрации.
- Добавлен сценарий горизонтального масштабирования: несколько экземпляров приложения за Nginx.
- Настроены HTTPS на порту 443 и перенаправление HTTP на HTTPS; добавлен скрипт создания локального самоподписанного сертификата.
- Улучшена работа с PostgreSQL: настройки пула соединений и индекс имени пользователя.

### Тестирование и инструменты

- Добавлены тесты обработчиков, PostgreSQL-хранилища и интеграционные тесты API.
- Тестовая БД запускается через dockertest с образом PostgreSQL 18; ошибка её запуска завершает тесты с ненулевым кодом.
- Добавлены тестовый Compose и GitHub Actions workflow тестов.
- Проект переведён на Go 1.27.1, обновлены зависимости.
- Настройки golangci-lint перенесены в формат v2; версии Go и линтера согласованы с CI.
- В Makefile добавлена проверка конфигурации линтера перед анализом.
- Скрипт зависимостей получил явные режимы актуализации модулей, очистки кеша и удаления vendor; ошибки больше не скрываются.

### Docker и сопровождение

- Исправлен путь volume для PostgreSQL 18: `/var/lib/postgresql`.
- Удалён дублирующий simple Compose; scalable использует настройки основного файла как дополнение.
- Убрана автоматическая очистка Docker volumes из целей сборки.
- Исправлен healthcheck приложения: используется доступный в образе wget.
- Удалены неиспользуемые файлы и готовый бинарник; локальные TLS-сертификаты исключены из Git.
- Шаблоны GitHub Issues перенесены в `.github/ISSUE_TEMPLATE`, исправлено имя русской лицензии.
- Обновлены README и инструкции тестирования, добавлен скрипт проверки API через curl.

### При обновлении

- Основной стек и тесты используют PostgreSQL 18. Существующая БД предыдущей основной версии требует отдельной миграции; замена тега образа и пути volume не переносит данные автоматически.
- Scalable запускается с обоими файлами: `-f docker-compose.yml -f docker-compose.scalable.yml --profile scalable`. Требуется Compose с поддержкой `!reset` (2.24.0+).
- Перед первым HTTPS-запуском выполните `bash scripts/setup-tls.sh` либо установите собственные сертификат и ключ. Самоподписанный сертификат предназначен для локальной проверки.

## v1.0.0 - 2025-07-08

Первый помеченный выпуск проекта.

- OAuth2-сервер с JWT и хранением токенов в памяти.
- Регистрация пользователей и клиентов с хранением в PostgreSQL.
- Endpoint-ы авторизации, выдачи и интроспекции токенов, регистрации и проверки здоровья.
- Миграции БД при старте, настройка через окружение и `.env`.
- Структурированное логирование, CORS и корректное завершение HTTP-сервера.
- Маршрутизация Gorilla Mux, Dockerfile и начальная настройка линтера в GitHub Actions.

[Снимок v1.0.0](https://github.com/akozadaev/go_oauth2_server/tree/v1.0.0).
